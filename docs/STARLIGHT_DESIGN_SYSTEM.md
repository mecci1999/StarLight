# StarLight 微服务监控 - 专业设计系统

## 设计理念

**专业、清晰、高效** — 专为 DevOps 和开发人员设计的监控界面

- **数据优先** - 关键指标一目了然
- **层次分明** - 通过间距和颜色建立清晰的视觉层级
- **响应迅速** - 快速的交互反馈和流畅的动画
- **专业可信** - 类似 Datadog/New Relic 的专业体验

## 组件设计规范

### 1. 卡片 (Card)

**样式：**
- 背景：白色 `--color-bg-white`
- 边框：1px `--color-border-1`
- 圆角：`--border-radius-large` (8px)
- 阴影：默认 `--shadow-sm`，悬浮 `--shadow-md`
- 内边距：`--spacing-4` (16px)

**结构：**
```
┌─────────────────────────┐
│  Card Header (可选)     │  ← padding: 16px 16px 0
├─────────────────────────┤
│                         │
│  Card Body              │  ← padding: 16px
│                         │
├─────────────────────────┤
│  Card Footer (可选)     │  ← padding: 0 16px 16px
└─────────────────────────┘
```

### 2. 按钮 (Button)

**主按钮：**
- 背景：`--color-primary-6`
- 文字：白色
- 圆角：`--border-radius-medium` (4px)
- 高度：36px
- 内边距：0 16px
- 字重：500
- 悬浮：`--color-primary-5`

**次要按钮：**
- 背景：透明
- 边框：1px `--color-border-2`
- 文字：`--color-text-2`
- 悬浮：背景 `--color-fill-2`

**文字按钮：**
- 背景：透明
- 文字：`--color-text-2`
- 悬浮：背景 `--color-fill-2`

### 3. 输入框 (Input)

使用 Naive UI 默认样式，不做过多自定义。

**关键样式：**
- 高度：36px
- 圆角：`--border-radius-medium` (4px)
- 内边距：0 12px
- 边框：1px `--color-border-2`
- 悬浮：边框 `--color-border-3`
- 聚焦：边框 `--color-primary-5` + 品牌色外发光

### 4. 状态标签 (Status Tag)

**样式规范：**

| 状态 | 背景色 | 文字色 | 示例 |
|------|--------|--------|------|
| **健康** | `--color-success-1` | `--color-success-7` | 绿色 |
| **警告** | `--color-warning-1` | `--color-warning-7` | 橙色 |
| **异常** | `--color-danger-1` | `--color-danger-7` | 红色 |
| **未知** | `--color-fill-2` | `--color-text-2` | 灰色 |

**尺寸：**
- 高度：24px
- 内边距：2px 8px
- 字号：12px
- 圆角：`--border-radius-small` (2px)

### 5. 统计卡片 (Metric Card)

**用于展示关键指标：**

```
┌─────────────────────────┐
│  [图标]        [趋势]   │  ← 图标左，趋势右
│                         │
│  1,234                  │  ← 大数字，24-32px
│  请求/秒                │  ← 标签，14px，灰色
└─────────────────────────┘
```

**样式：**
- 背景：白色
- 边框：1px `--color-border-1`
- 圆角：8px
- 内边距：16px
- 阴影：`--shadow-sm`

## 交互规范

### 动画过渡

| 场景 | 时长 | 缓动函数 |
|------|------|---------|
| 悬浮反馈 | 150ms | `ease-out` |
| 展开/收起 | 200ms | `cubic-bezier(0.4, 0, 0.2, 1)` |
| 弹窗显示 | 200ms | `cubic-bezier(0.4, 0, 0.2, 1)` |
| 页面切换 | 300ms | `cubic-bezier(0.4, 0, 0.2, 1)` |

### 悬浮反馈

**可悬浮元素：**
- 按钮：背景色变化
- 卡片：阴影增强 + 轻微上移 (2px)
- 菜单项：背景色变化
- 链接：文字颜色变化

### 点击反馈

- 按钮：瞬时背景色加深
- 避免缩放变换（会导致布局抖动）

### 聚焦状态

- 输入框：品牌色边框 + 浅色外阴影
- 所有可聚焦元素：可见的聚焦指示

## 深色模式

### 设计原则

- 保持相同的信息层级
- 降低对比度，避免刺眼
- 功能色保持色相不变，调整明度
- 阴影可以稍加重，增加层次感

### 关键颜色映射

| 浅色模式 | 深色模式 |
|----------|----------|
| 页面背景 `#f7f8fa` | `#171717` |
| 卡片背景 `#ffffff` | `#1e1e1e` |
| 边框 `#e5e6eb` | `#404040` |
| 文字主色 `#1d2129` | `#f5f5f5` |
| 文字次色 `#4e5969` | `#d4d4d4` |

## 检查清单

开发新页面/组件前确认：

- [ ] 使用统一的间距变量 (`--spacing-*`)
- [ ] 使用统一的颜色变量 (`--color-*`)
- [ ] 使用统一的圆角变量 (`--border-radius-*`)
- [ ] 使用统一的阴影变量 (`--shadow-*`)
- [ ] 字体层级清晰，不超过 3-4 种字号
- [ ] 字重不超过 3 种 (400, 500, 600)
- [ ] 交互反馈一致（悬浮、点击、聚焦、禁用）
- [ ] 动画时长合理 (150-300ms)
- [ ] 考虑了深色模式适配
- [ ] 可访问性：文字对比度 4.5:1+
